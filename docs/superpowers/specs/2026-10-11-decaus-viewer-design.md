# デカウス空間ビューア 設計書

日付：2026-10-11
出典：加藤「思索の散歩道 — デカウス空間」 https://kato.chobi.net/descaus/index.html

## 1. 目的

実係数の多項式 y = f(x) について、x を複素数に広げたときに y が実数となる点の集合を、
3次元空間（Re x, Im x, y）に描き、マウスで回して見られるブラウザアプリを作る。

- 実曲線（Im x = 0 の部分）は黒で描く。
- 虚曲線は、**真上から見て（ガウス平面へ射影して）一本につながる曲線を同じ色**で描く。
- 加藤氏の添付図（y = x³, y = x⁴, 一般3次・4次）と同じ形が再現できること。

## 2. 範囲

- 対象：実係数の多項式のみ。次数 n = 1〜8。
- 有理関数・陰関数・初等関数は対象外（必要になったら別の仕様とする）。
- 外部ライブラリなし。Canvas 2D による自前の3D投影。`file://` で開ける。

## 4. 計算の中核（core.js）

### 4.1 入口

```
Decaus.compute(coeffs) → {
  strands:   [{ real: bool, colorIndex: int|null, ends: [k1, k2],
                points: [[Re x, Im x, y], ...] }],
  roots:     [{re, im}, ...]          // f(x) = 0 の n 個の解
  centroid:  number                   // −a_{n−1} / (n · a_n)
  vertices:  [{ x: {re, im}, y, m }]  // f(c) が実数の臨界点 c、次数 m（f′ の零点の重複度）
  degenerate: bool                    // 重根の臨界点、または非実の頂点があるか
  check:     { ok: bool, message: string }
}
```

`coeffs` は `[a_n, a_{n−1}, …, a_0]`（高次から）。a_n = 0 なら例外を投げる。

### 4.2 原理

x = a + bi とする。曲線上では f(x) が実数なので、f′(x)·dx も実数。
よって進行方向は conj(f′(x)) の方向、曲線への補正は Newton 法

    x ← x − i · Im f(x) / f′(x)

（目標値 Re f(x) を保ったまま Im f を 0 にする）。

臨界点 c（f′ の m 重零点）の近くでは f(x) ≈ f(c) + k(x − c)^(m+1) なので、
f(c) が実数なら曲線は c で 2(m+1) 本の枝として、π/(m+1) ずつの等角で交わる。

多項式では Im f が調和関数なので閉じた輪は無く、すべての曲線は両端が無限遠に伸びる。
無限遠での漸近方向は偏角 θ_k = (kπ − arg a_n)/n（k = 0 … 2n−1）の 2n 本。

### 4.3 手順

1. **根**：Aberth 法で f と f′ の根を求める。
   - 重根の判定：近接した根を集め、集まりの平均点で f′, f″, … を評価して重複度を確定する
     （Aberth は m 重根を半径 ε^(1/m) 程度にばらけて返すため、近さだけでは判定しない）。
2. **頂点**：f′ の零点 c のうち f(c) が実数のもの。
   - Im c ≈ 0 の零点は実数に丸める（実係数なので f(c) は厳密に実数）。
   - 非実の c は |Im f(c)| が相対許容誤差以下なら頂点とする（例：x⁴ + x² の ±i/√2）。
   - 許容誤差は数値誤差を吸収できる最小限とする。
3. **始点**
   - (a) 遠方円 |x| = R_far 上で、2n 本の漸近方向 θ_k の近くの点を Newton 補正して始点とする。
     R_far は f と f′ の根の上界から自動で決める（全根・全臨界点を十分内側に含む大きさ）。
   - (b) 各頂点から出る 2(m+1) 本の枝の方向。
4. **追跡**：予測（conj(f′) 方向へ歩幅 h）→ 補正（上式の Newton）を繰り返す。
   - 歩幅：h ≤ 0.1 · d（d は現在点から最も近い f′ の零点までの距離）。かつ上限・下限を設ける。
     根拠：Grace–Heawood の定理（f(z₁) = f(z₂) なら中点中心・半径 |z₁−z₂|/2·cot(π/n) の円内に臨界点がある）。
     臨界点から距離 d の点の周り半径 d/(1+cot(π/n)) の円では f は単射なので、Newton 補正が別の枝へ移らない。
   - 終了：頂点の吸着半径内に入ったら頂点に合わせて止める。遠方円の外へ出たら止め、漸近方向 k を記録する。
   - 既に到達済みの端から始まる枝は飛ばす。
   - 毎歩の確認：y が単調に動くこと、進行方向が急に折れないこと。破れたら歩幅を半分にして再試行。
5. **曲線（strand）へのまとめ**：頂点では向かい合う枝（i 番目と i+(m+1) 番目）をつなぐ（通り抜けの規則）。
   実軸上の枝を含む曲線は `real: true`（黒）。
6. **色番号**：虚曲線ごとに両端の漸近方向番号の小さいほうで並べ、0, 1, 2, … を振る。
   パレット：赤・青・緑・橙・紫・青緑・茶（n ≤ 8 なら虚曲線は最大 n − 1 本）。
7. **検算**（`check`）
   - 漸近方向 k ごとに端がちょうど1つ。
   - 各虚曲線の端がちょうど2つ。
   - 実曲線は実軸の両方向（正・負）の端を持つ。
   - いずれか不成立なら全体を歩幅半分で再計算し、なお不成立なら `ok: false` と理由を返す。

### 4.4 色分けの規則の性質（取り違えではない色の変化）

通り抜けの規則は退化点で不連続になる。例：f = x³ − εx の虚曲線は b² = 3a² − ε で、

| ε | 形（真上から） | つながる漸近方向 |
|---|---|---|
| ε > 0 | 左右に開く双曲線（臨界点を垂直に通る） | 60°–300°, 120°–240° |
| ε = 0 | 原点で交わる2直線（通り抜け） | 60°–240°, 120°–300° |
| ε < 0 | 上下に開く双曲線（実軸に触れない） | 60°–120°, 240°–300° |

スライダーで退化点を通過すると、その1点でだけ色の組み合わせが変わる。これは仕様とする。
退化点（重根の臨界点、または非実の頂点）があるときは画面に
「退化点あり：通り抜けの規則で色を付けています」と表示する。

添付図3枚目右（停留変曲点）では、図の作者は上下の向きで緑・赤・青に塗り分けているが、
本アプリは真上から見たつながりで塗るため、「緑と赤」「緑と青」がそれぞれ1色になる。合意済み。

## 5. 画面と操作（index.html / view.js）

- 配置：左に操作パネル、右に Canvas。狭い画面では上下。背景は白。
- 入力：次数 n（1〜8）、係数 a_n … a_0 ごとに数値欄＋スライダー（±5、数値欄は範囲外も可）。
  a_n = 0 のときは計算せず警告し、直前の図を残す。
- プリセット（係数はちょうどの値）：

| 名前 | 式 |
|---|---|
| 2次（虚数解） | x² − 2x + 2 |
| 基本形3次 | x³ |
| 基本形4次 | x⁴ |
| 3次・極値2つ | x³ − 3x |
| 4次・極値3つ | x⁴ − 2x² |
| 4次・極値＋変曲点 | x⁴ + (4/3)x³ |

- 表示の切り替え：軸（Xr, Xi, Y のラベル）、ガウス平面（y = 0 の半透明の格子）、
  解（ガウス平面を貫く点）、解の重心（x = −b/(an) を通る鉛直線）、臨界点（頂点の印）。
- 線：実曲線は黒の太い実線、虚曲線は色付きの実線。
- 視点：ドラッグで回転（方位角・仰角）、ホイールで拡大縮小。平行投影。
  ボタン「真上」（Xr 右・Xi 上）、「真横」（Xr 右・Y 上）、「斜め」（初期視点）。
- 表示範囲：x の箱の半幅 R と y の範囲 ±Y。「自動」で根と臨界点が収まるように合わせる（初期は自動）。
  切り取りは描画時に行い、計算・色分け・検算は表示範囲に依存しない。
- 状態表示：解の数値一覧、重心の値、警告（検算失敗、退化点の注記）。

## 6. テスト

`D:\node-v24.20.0-win-x64\node.exe --test tests/` で実行。

- 根：既知の根、重根とその重複度。
- 頂点：x⁴ + x² で ±i/√2 を頂点として拾う。
- 色分けの規則：x³ は直線2本で 60°–240°・120°–300°。x³ ∓ εx は 4.4 の表どおり。
  x⁴ + (4/3)x³ の停留変曲点で通り抜け。
- 幾何：x² − 2x + 2 の虚曲線が a = 1, y = 1 − b² の上。全点で |Im f| が小さい。頂点間で y が単調。
- 乱数：n = 1〜8 の乱数係数で数百通り、すべて `check.ok`。
- 画面：ブラウザで各プリセットを「真上」「真横」に切り替えて撮影し、添付図と見比べる。
